# AI Usage Documentation

## Project

Job Tracker Application — COP4751

## AI Tool Used

ChatGPT was used as an assistant during the development and debugging of the Job Tracker web application.

## Purpose of AI Assistance

AI assistance was used to help understand Flask application development, organize HTML templates, improve CSS styling, troubleshoot errors, and implement application features.

## Areas Where AI Assisted

### 1. Flask and Python

AI assistance helped with understanding Flask routes, rendering templates, processing form submissions, redirecting between pages, and connecting application code to the MySQL database.

### 2. Database Integration

AI assistance helped explain database queries, retrieving records, displaying summary counts, and connecting related records across the application's database tables.

### 3. HTML Templates

AI assistance helped create and revise templates for the dashboard, companies, jobs, applications, contacts, and Job Match pages. The templates were updated to use a shared base layout.

### 4. CSS and User Interface

AI assistance helped organize the shared stylesheet, improve navigation, style tables and forms, and create dashboard cards and skill-match progress indicators.

### 5. Debugging and Corrections

AI assistance helped troubleshoot problems encountered during development. One example was correcting the dashboard so that the contacts total was retrieved from the database and passed to the template.

The Job Match template was also revised to use the shared layout and display entered skills, matching results, and match percentages.

### 6. Testing

The application was run locally, and the pages were tested during development. Testing helped verify that the dashboard, company management, job listings, application management, contact management, and Job Match features worked.

## Example Prompts

The following examples summarize the types of prompts used during development:

- Help me build a Job Tracker application using Flask and MySQL.
- Help me troubleshoot errors in my Flask routes and database queries.
- Help me update HTML templates to extend a shared base template.
- Help me style the application using a shared CSS file.
- Help me implement a feature that compares user skills with job requirements.
- Help me test the application's pages and prepare the final project documentation.

These are representative examples of the assistance requested, not necessarily exact copies of every prompt.

## Student Contributions and Verification

AI-generated suggestions were reviewed and incorporated into the project during development. The application was run locally, and features were tested to verify their behavior. Errors and inconsistencies discovered during testing were addressed as development continued.

The student remains responsible for understanding the submitted code, verifying that it meets the assignment requirements, and ensuring the final application and documentation are accurate.

## Lessons Learned

This project provided practice with:

- Connecting a Flask application to a MySQL database.
- Using SQL queries to retrieve and modify data.
- Building web pages with HTML and Jinja2 templates.
- Applying consistent styling with CSS.
- Implementing CRUD operations.
- Connecting related database records.
- Comparing skills against job requirements.
- Testing and debugging a multi-page web application.
- Using AI assistance as a development aid while checking the resulting code.
